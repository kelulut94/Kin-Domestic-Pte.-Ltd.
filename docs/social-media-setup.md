# Social media setup: Instagram and Facebook

How to create Kin Domestic's Facebook Page and Instagram account under **hello@kindomestic.com**,
with copy ready to paste. Sign-up has to be done by a person: Meta sends verification codes to the
email inbox and may ask for a phone number.

## Before you start

- Access to the **hello@kindomestic.com** inbox (for verification codes)
- A mobile number for two-factor authentication (the agency number +65 9375 7030 works if it can receive SMS)
- Profile picture: `images/favicon-512.png` (square, 512 × 512). If it looks odd on a dark background,
  put it on a cream (`#FDF6F1`) square first.
- Cover photo (Facebook): 1640 × 624 recommended. `images/hero.jpg` is portrait, so make a wide banner
  in Canva using the logo and brand colours: plum `#824C4C`, dusty rose `#A77B7C`, blush `#E8C8C0`,
  cream `#FDF6F1`, rust `#B5533C`.

## Step 1: Facebook Page

Facebook Pages must be created from a personal Facebook profile. Use an owner's or director's personal
profile, then add a second admin later so the Page is never locked to one person.

1. Log in to Facebook and go to **facebook.com/pages/create**.
2. **Page name:** `Kin Domestic`
3. **Category:** `Employment Agency` (add `Household Service` as a second category if offered).
4. **Bio** (up to 101 characters):

   ```
   MOM-licensed maid agency in Singapore for Myanmar helpers. EA Licence No. 26C3706.
   ```

5. Click **Create Page**, then fill in the details:
   - **Email:** hello@kindomestic.com
   - **Phone / WhatsApp:** +65 9375 7030
   - **Website:** https://www.kindomestic.com
   - **Address:** leave hidden unless you receive walk-in visitors
   - **Hours:** your office hours, or "Always open" if you reply on WhatsApp anytime
6. Upload the profile picture and cover photo.
7. **Settings → Username:** set it to the handle chosen above (gives facebook.com/kindomestic).
8. **Add action button → WhatsApp** and link +65 9375 7030.
9. **Settings → Page setup → Page access:** add a second admin.
10. Turn on two-factor authentication on every admin's personal profile.

## Step 2: Instagram account

1. Install Instagram and choose **Create new account**.
2. Sign up with **email** and enter hello@kindomestic.com. Enter the code sent to the inbox.
3. **Name:** `Kin Domestic | Maid Agency SG` (30 characters max; the name field is searchable, so the
   keywords help people find you)
4. **Username:** the handle chosen above.
5. **Settings → Account type and tools → Switch to professional account → Business**.
   Category: `Employment Agency`. Show contact options: email and phone.
6. **Bio** (up to 150 characters):

   ```
   MOM-licensed maid agency 🇸🇬
   Myanmar helpers · fresh, experienced & transfer
   Care that feels like kin.
   EA Licence 26C3706
   WhatsApp 9375 7030 👇
   ```

7. **Links:** https://www.kindomestic.com
8. **Contact options:** email hello@kindomestic.com, phone/WhatsApp +65 9375 7030.
9. Turn on two-factor authentication: **Settings → Accounts Centre → Password and security**.

## Step 3: Link Instagram to the Facebook Page

1. Open **business.facebook.com** (Meta Business Suite) with the Facebook profile that admins the Page.
2. **Settings → Business assets → Instagram accounts → Connect** and log in to the Instagram account.

Once linked you can schedule posts to both platforms together, reply to Facebook and Instagram messages
in one inbox and set up automatic replies (for example, a greeting that points people to WhatsApp).

## Advertising rules (MOM)

Employment agency licence conditions apply to social media posts too:

- Show the EA licence number (**26C3706**) on the profile and in ads.
- Don't present helpers as commodities: no "discount", "sale" or "promotion" wording about helpers
  themselves, and no posts ranking or comparing helpers by price.
- Only post a helper's photo or video with her consent, and never post passport, FIN, work permit number,
  date of birth, address or personal contact details (same rules as `data/helpers.json`).

Check the current MOM advertising guidelines for employment agencies before running paid ads.
